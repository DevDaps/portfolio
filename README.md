## 🎨 Design System

O portfólio utiliza um Design System profissional chamado **Industrial Digital** com:

### Paleta de Cores
- **Black 950**: #080808 (background principal)
- **Black 900**: #111111 (cards/superfícies)
- **Black 800**: #1A1A1A (borders/dividers)
- **White 100**: #F2F2F2 (títulos/textos principais)
- **Gray 400**: #969696 (textos secundários)
- **Red**: #D71920 (energia/ação - cor de assinatura)
- **Moss**: #596B3A (humano/orgânico)
- **Blue**: #2457E6 (tecnologia)

### Tipografia
- **Display/Headings**: Space Grotesk (Google Fonts)
- **Body**: Inter (Google Fonts)

### Componentes
- Border Radius: 3px-12px
- Spacing Scale: 4px-64px
- Animações: fadeIn, slideUp, zoomIn

## 🚀 Como Usar

### Local Development

```bash
# Clonar o repositório
git clone https://github.com/DevDaps/portfolio.git
cd portfolio

# Abrir em um servidor local (Python)
python -m http.server 8000

# Abrir em um servidor local (Node)
npx http-server

# Abrir em um servidor local (PHP)
php -S localhost:8000
```

Acesse: `http://localhost:8000`

### Deploy

#### GitHub Pages
1. Vá para Settings → Pages
2. Source: main branch
3. Save
4. Site em: `https://devdaps.github.io/portfolio`

#### Vercel (Recomendado)
1. Vá para https://vercel.com
2. Import Project
3. Selecione o repositório
4. Deploy automático

#### Netlify
1. Vá para https://netlify.com
2. Connect GitHub
3. Selecione o repositório
4. Deploy automático
